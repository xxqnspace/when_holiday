# when_holiday · 什么时候放假啊

一个**学期倒计时与进度追踪**网页应用，可在手机桌面以 PWA 方式安装使用。实时显示学期已过百分比、剩余天数、工作日倒计时，并附带学期日历视图和管理后台。
用于在枯燥的生活中给予我们前进的力量与希望。

---

## 技术栈

| 层面 | 技术 |
|------|------|
| 后端 | PHP（纯原生，无框架） |
| 存储 | JSON 文件（`data/db.json.php`，无需数据库） |
| 前端 | 原生 HTML + CSS + JavaScript + Font Awesome（国内 CDN） |
| PWA | Service Worker + Manifest |
| 部署 | 可依托宝塔面板（无需配置数据库） |

---

## 核心功能

### 首页（`index.php`）
- **学期进度条** — 精确到 6 位小数的百分比进度
- **总倒计时** — 学期结束的 天:时:分:秒 实时倒计时
- **工作日倒计时** — 排除周末和自定义假期的有效天数
- **学期日历** — 按月展示学期范围内的日历，标注：
  - 已过日期（浅绿）、节假日（浅蓝）、工作日（白色）、当天（高亮）、周次列
  - **大屏默认展开全部月份，手机小屏默认只显示当前月份**（自动响应式）
- **公告栏** — 支持 Markdown，可配置展示窗口和自动关闭秒数
- **PWA 支持** — 安装至手机桌面，支持离线缓存静态资源
- **可定制 UI** — 主题色、字体色、背景色、进度条颜色均可在管理面板调整；支持纯色或图片背景（毛玻璃效果）

### 管理面板（`admin.php`）
- 登录页面（用户名/密码验证，PHP 会话 + CSRF 防护）
- **用户管理**（管理员专属）— 创建/编辑/删除用户，分配角色
- **学期配置** — 设置起止时间、自定义假期、补班日
- **界面配色** — 自定义主题色、字体色、背景色等
- **背景设置** — 纯色或图片背景，支持毛玻璃透明度调节
- **公告管理** — 创建/编辑/删除公告，控制展示时间范围
- **修改密码** — 所有用户可自行修改密码

### API 层（`api.php`）
JSON 接口，覆盖认证、用户管理、配置读写、公告管理，写操作均带 CSRF 校验。

## 项目结构

```
/
├── index.php          # 首页（倒计时 + 日历展示）
├── admin.php          # 管理面板（登录 + 后台管理）
├── api.php            # JSON API 接口
├── config.php         # 默认配置（兜底值）

```

## 数据存储（JSON，无需 MySQL）

所有数据（用户、配置、公告）保存在 `data/db.json.php`，首次访问自动创建：

- **文件伪装**：数据文件首行含 `<?php exit; ?>`，浏览器直接访问 URL 只得到空白页，数据不会泄露（无需配置 Nginx/Apache）
- **原子写入**：临时文件 + rename，防止写一半损坏
- **并发安全**：flock 文件锁，读-改-写一体
- **自动迁移**：兼容旧版 `data/db.json` 纯 JSON 格式

> ⚠️ `data/db.json.php` 含用户密码哈希等敏感信息，已通过 `.gitignore` 排除，不会提交到仓库。

## 部署要点

1. 将整个目录上传到网站根目录（PHP ≥ 7.4 即可，无需 MySQL）
2. 首次访问自动创建 `data/db.json.php`，请确保 `data/` 目录有写权限（755/775）
3. 默认管理员账号：`admin / admin123`，**登录后请立即修改密码**
4. 可选：如使用 Nginx 且希望更保险，可额外在站点配置加 `location ~ ^/data/ { deny all; }`（非必需）

---

## 数据流

```
首页/index.php
    └─ config.php（默认配置兜底）
    └─ countdown.php（从 data/db.json.php 读取配置，失败则 fallback）
        └─ 注入前端 JS 变量 → 浏览器端实时倒计时
        └─ 加载 date.php 生成日历 HTML
```
