## 项目概述

一个**学期倒计时与进度追踪**网页应用，可在手机桌面以 PWA 方式安装使用。实时显示学期已过百分比、剩余天数、工作日倒计时，并附带学期日历视图和管理后台。
用于在枯燥的生活中给予我们前进的力量与希望

---

## 技术栈

| 层面 | 技术 |
|------|------|
| 后端 | PHP（纯原生，无框架） |
| 前端 | 原生 HTML + CSS + JavaScript |
| 数据库 | MySQL（3 张表） |
| PWA | Service Worker + Manifest |
| 部署 | 可依托宝塔面板 |

---

## 核心功能

### 首页（`index.php`）
- **学期进度条** — 精确到 6 位小数的百分比进度
- **总倒计时** — 学期结束的 天:时:分:秒 实时倒计时
- **工作日倒计时** — 排除周末和自定义假期的有效天数
- **学期日历** — 按月展示学期范围内的日历，标注：
  - 已过日期（浅绿）
  - 节假日（浅蓝）
  - 工作日（白色）
  - 当天日期（高亮）
  - 左侧周次列
- **公告栏** — 支持 Markdown，可配置展示窗口和自动关闭秒数
- **PWA 支持** — 安装至手机桌面，支持离线缓存静态资源
- **可定制 UI** — 主题色、字体色、背景色、进度条颜色均可在管理面板调整；支持纯色背景或图片背景（毛玻璃效果）

### 管理面板（`admin.php`）
- 登录页面（用户名/密码验证，PHP 会话保持）
- **用户管理**（管理员专属） — 创建/编辑/删除用户，分配角色
- **学期配置** — 设置起止时间、自定义假期、补班日
- **界面配色** — 自定义主题色、字体色、背景色等
- **背景设置** — 纯色或图片背景，支持毛玻璃透明度调节
- **公告管理** — 创建/编辑/删除公告，控制展示时间范围
- **修改密码** — 所有用户可自行修改密码

### API 层（`api.php`）
RESTful JSON 接口，覆盖认证、用户管理、配置读写、公告管理。

## 项目结构

```
/
├── index.php          # 首页（倒计时 + 日历展示）
├── admin.php          # 管理面板（登录 + 后台管理）
├── api.php            # JSON API 接口
├── config.php         # 默认配置（兜底值）
├── countdown.php      # 数据处理模块（数据库 → 前端配置转换）
├── date.php           # 日历生成模块
├── db.php             # 数据库连接类（单例 PDO）
├── install.php        # 数据库初始化脚本
├── manifest.json      # PWA 清单
├── sw.js              # Service Worker（离线缓存策略）
└── icons/             # PWA 图标（72×72 至 512×512）
```

---

## 数据库结构（MySQL）

| 表名 | 说明 |
|------|------|
| `users` | 用户表：用户名、密码（bcrypt 哈希）、角色（admin/user） |
| `settings` | 配置表：key-value 形式存储学期时间、UI 配色等设定 |
| `announcements` | 公告表：内容、展示起止时间、是否激活 |

---

## 数据流

```
首页/index.php
    └─ config.php（默认配置兜底）
    └─ countdown.php（尝试从数据库加载配置，失败则 fallback）
        └─ 注入前端 JS 变量 → 浏览器端实时倒计时
        └─ 加载 date.php 生成日历 HTML
```

---

## 部署要点

1. 创建 MySQL 数据库
2. 修改 `db.php` 中的数据库连接信息
3. 访问 `install.php` 初始化数据表并写入默认设置
4. **必须删除 install.php**（安装脚本本身有醒目提示）
5. 部署后通过管理面板修改默认凭据和学期配置

> 注：本文档已对代码中所有敏感信息（数据库凭据、默认账号密码、站点地址等）做脱敏处理。
